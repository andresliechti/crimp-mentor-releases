# Crimp Mentor – Android app

Finger training for climbing with the Tindeq Progressor: programs, weekly plan, max/CF/RFD tests, history.

## Download

**[crimp-mentor.apk](https://github.com/andresliechti/crimp-mentor-releases/raw/main/crimp-mentor.apk)** – current version in `version.json`.

## Install (Android)

1. Open the link above on the phone. Chrome downloads the file.
2. Tap the finished file (notification or «Downloads»).
3. The first time Android asks whether Chrome may install apps: turn on **«Allow from this source»**, go back, **Install**.
4. If «Play Protect» warns: **«Install anyway»**. The app is not in the Play Store, so Google does not know it.
5. On first start allow Bluetooth («Nearby devices»).

## Updates

The app checks for a newer version at start and then shows «Update available» at the top. Tap **Install** → the
download runs in the app → confirm «Update» in the Android dialog. Your data stays.

This repository holds only the finished app, no code and no data.
